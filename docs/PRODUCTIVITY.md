# 🛠️ Productivity Tools

Beyond power monitoring, your device is equipped with a suite of offline productivity applets.

## 📝 Notes (Scribble Pad)

A responsive digital notepad for quick sketches and lists.

- **Tools**:
    - **Pen Sizes**: Thin, Medium, Thick.
    - **Eraser**: Remove strokes.
    - **Clear**: Wipe the entire page (Flash refresh).
- **Persistence**: Your current note is saved automatically when you switch apps.
- **Saving**:
    - Tap **Save** to write the current canvas to the SD card.
    - Format: 540x960 Bitmap (`.bmp`) in `/notes/`.
- **Browser**: Access past notes via the file browser menu.

## 🧮 Calculator

A classic desktop calculator for quick math.

- **Features**: Standard arithmetic (`+`, `-`, `*`, `/`).
- **Design**: Retro high-contrast buttons optimized for E-Ink.

## ⏱️ Timer & Pomodoro

Stay focused with built-in timing tools.

### Standard Timer
- Configurable countdown timer.
- Ideal for cooking, tasks, or reminders.

### Pomodoro Mode
- **Focus**: 25-minute work timer.
- **Break**: 5-minute rest timer.
- **Background Support**: Timers continue running even if you leave the app or the screen sleeps.

## 🎮 Games Center

Relax with distraction-free puzzle games.

### Sudoku
- **Difficulty**: Easy, Medium, Hard.
- **Smart Refresh**: Optimized to minimize ghosting during gameplay.
- **Input**: Tap a cell, then tap the number pad to fill.

### 2048
- **Goal**: Merge tiles to reach the number 2048.
- **Controls**: Swipe Up, Down, Left, Right to move tiles.
- **Auto-Save**: Your game state is preserved if you exit.
